LNTAI Algorithm Workflow
1. Data Acquisition
Contact temperature at 6 points/phase (MQTT), load current I_R/I_S/I_T (power meter), real-time ambient temperature (Open-Meteo API).
2. Preprocessing & Validation
Check completeness & value range. If invalid, the reading is discarded — the previous LNTAI value is retained. A 3-sample rolling median filters out single-reading sensor noise/spikes before scoring.
3. Parameter Aggregation
Average temperature per phase T_R/T_S/T_T, average current I_avg, Loading% = I_avg/I_nominal x100%.
4. Component Scores (0–40)
S_Temp and S_ΔT use an exponential Montsinger/Arrhenius curve (risk doubles every 10K) instead of a linear scale, so the score accelerates near the limit. S_TLR = temperature rise per unit load².
5. Weighted LNTAI Score
LNTAI = 0.40·S_Temp + 0.30·S_ΔT + 0.30·S_TLR. Result range: 0–40.
6. Classification
0–15 Normal · 15–30 Warning · 30–40 Critical.
7. Logging & Dashboard Update
Store the data & LNTAI score, refresh KPIs and trend charts in real time.
Engineering Interpretation

LNTAI is a weighted composite score, not a single temperature variable. Three components are each scored 0–40, then combined with weights 0.40/0.30/0.30 so the final result always falls within 0–40.

S_Temp scores the hottest contact's temperature rise above ambient against the reference terminal rise limit (IEC 62271-1), and S_ΔT scores the temperature difference between phases R/S/T (contact imbalance) — both on an exponential curve that doubles every 10K (Montsinger/Arrhenius rule-of-thumb), so the score climbs sharply as the reading approaches the limit rather than growing at a flat linear rate. S_TLR scores the temperature rise relative to the square of the load — an indicator of unusual heating relative to the current flowing.

Invalid or incomplete data (sensor dropout, out-of-range values) is not used to compute a new score — the dashboard keeps showing the last valid LNTAI value until the next reading is complete. A 3-sample rolling median additionally smooths out single-reading sensor noise before it reaches the score.

LNTAI = 0.40·S_Temp + 0.30·S_ΔT + 0.30·S_TLR  →  result range 0–40

LNTAI is not an absolute temperature alarm. This score combines contact temperature rise, inter-phase imbalance, and the plausibility of heating relative to load into a single 0–40 number, so a high score can indicate rising finger-contact resistance even when the absolute temperature is not yet very high.

Cara Kerja — Holt-Winters Double Exponential Smoothing (DES)
IEC 61000-4-30 · Box-Jenkins

Algoritma peramalan deret waktu yang menggunakan dua komponen: Level (L) yang merepresentasikan nilai rata-rata saat ini, dan Trend (T) yang merepresentasikan arah perubahan. Dua parameter smoothing (α dan β) mengontrol seberapa cepat model beradaptasi terhadap data baru — nilai kecil memberi bobot lebih pada data historis, nilai besar lebih responsif terhadap perubahan terkini.

📥
Step 1
Kumpulkan Data
Ambil N titik terbaru dari Firestore (suhu/beban) dan urutkan secara kronologis
🔄
Step 2
Update Level α
Lₜ = α·yₜ + (1−α)·(Lₜ₋₁ + Tₜ₋₁), α=0.30
📈
Step 3
Update Trend β
Tₜ = β·(Lₜ−Lₜ₋₁) + (1−β)·Tₜ₋₁, β=0.10
🔮
Step 4
Forecast h Langkah
F̂(h) = Lₙ + h·Tₙ — proyeksi linear dari kondisi terakhir
📊
Step 5
Hitung CI 95%
CI = ±1.96·σ·√(Σ[1+(h−1)·β]²) — Brown (1959) variance propagation
Formula Inti:
Lₜ = α·yₜ + (1−α)·(Lₜ₋₁+Tₜ₋₁)
Tₜ = β·(Lₜ−Lₜ₋₁) + (1−β)·Tₜ₋₁
F̂(t+h) = Lₙ + h·Tₙ — linear trend extrapolation
Ketidakpastian Forecast (Brown 1959):
Var(h) = σ²·Σᵢ₌₀ʰ⁻¹[1+(h−1−i)·β]²
CI 95% = ±1.96·√Var(h) | σ = RMSE residual in-sample
